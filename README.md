# Data Thermodynamics · 数据热力学

> **数据本身具备热量。**
> *Data itself possesses heat.*

---

## 关于本项目

数热学（Data Thermodynamics）是一门研究数据价值如何产生、流动、转化、耗散与再生的交叉学科框架。它以热力学为**首选隐喻语言**（而非本体主张），借用温度、热量、熵、相变等概念构建关于数据价值动力学的可检验命题体系。

其核心假设：

> 数据本身具备“热量”——即单位数据量中所蕴含的可行动价值势能。数据经加工升温，经消费降温，整体遵循数据热量守恒定律。

### 可检验的核心命题

数热学的实质内容不在隐喻里，而在以下可证伪假设中：

| 假设 | 内容 | 推翻条件 |
| ------ | ------ | ---------- |
| **价值守恒** | 数据价值在转化过程中不消失，只转化形态 | 观察到无法追溯的输出价值或价值总量不可解释增减 |
| **梯度驱动** | 数据价值梯度是做功的前提，封闭系统中梯度必然衰减 | 封闭系统在无外部输入条件下梯度自发维持或增大 |
| **效率上限** | 数据加工效率存在理论上限 | 观察到效率可无限逼近甚至超越100% |
| **稳态可达** | 开放系统可通过持续负熵输入维持非平衡稳态 | 充分负熵输入下仍无法维持梯度，或稳态对扰动完全无弹性 |

### 隐喻的本体论地位

**热力学不是数热学的本体，而是数热学的语言。** 数据化学、数据生态学、数据流体力学等其他隐喻框架同样可能成立。它们描述同一对象的不同层面，不构成对数热学的否定。一个对象的多种有效描述是理论成熟的标志。

**阶段：理论提案**

## 核心概念（速览）

| 概念 | 定义 |
| ------ | ------ |
| **数据温度** | 单位数据量在特定场景中的可行动价值密度，是关系属性而非固有属性 |
| **升温** | 数据经加工提升价值密度，需要外部能量输入 |
| **降温** | 数据被消费、扩散或时间衰减后，价值标的消失 |
| **热量守恒** | 数据价值不会消失，只会转化为知识、决策、行为和新数据 |
| **数据热寂** | 封闭系统中所有数据温度趋同，无法再做功 |
| **缪斯稳态** | 理想数据生态系统的假想状态，非平衡动态平衡，核心能力是热力弹性 |

## 替代隐喻

数热学的合法性不依赖于热力学隐喻的不可替代性。以下替代框架同样可能成立：

| 隐喻框架 | 核心问题 | 与数热学的关系 |
| ---------- | ---------- | ---------------- |
| **数据化学** | 数据如何结合生成新数据 | 互补层面 |
| **数据生态学** | 数据物种如何竞争、共生、演化 | 互补层面 |
| **数据流体力学** | 数据流如何运动、湍流如何形成 | 互补层面 |

替代隐喻的成立不否定数热学。数热学提供元层面的约束：守恒、不可逆、效率上限。
