# Data Thermodynamics · 数据热力学

> **数据本身具备热量。**
>
> *Data itself possesses heat.*

---

## 关于本项目

**数热学（Data Thermodynamics）**是一套研究数据系统中**可行动价值（actionable value）**如何产生、流动、转化、耗散与再生的跨学科理论框架。

数热学以热力学作为一种**理论语言与结构性隐喻**，尝试描述数据价值的梯度、流动、转化、耗散与反馈。

> **热力学不是数热学的本体，而是数热学目前采用的理论语言。**

具体概念、命题、形式化方法及其局限，请参阅 [00-INITIAL.md](docs/00-INITIAL.md)。

## 项目状态

**阶段：理论提案 / 开放演化框架**

数热学目前尚未被现代学术共同体正式承认为独立学科。

本项目不预设自身理论正确。核心命题可以被检验、修正、替换，甚至推翻。

数热学的合法性最终取决于：

> **这些概念是否能够形成具有独立解释力、可操作化、可检验的研究命题。**
